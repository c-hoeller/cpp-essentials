Schreiben Sie eine Funktion int anzahlGrossbuchstaben(const string & str), die zählt, wie viele Großbuchstaben ('A' bis 'Z') in der übergebenen Zeichenkette enthalten sind, und diese Anzahl zurückgibt.

Beispiel: anzahlGrossbuchstaben("Hallo Welt") → 2 (H, W).

Lösung

C++
#include <iostream>
#include <cstdlib>
#include <string>
using namespace std;
#include "eval.h"

int anzahlGrossbuchstaben(const string &str)
{
  int count = 0;

  int A = 'A';
  int Z = 'Z';

  for (int i = 0; i < str.length(); i++)
  {
    int x = str[i];

    if (x >= A && x <= Z)
      count++;
  }

  return count;
}
