C++ bietet mit try/catch/throw strukturierte Fehlerbehandlung. In reinem C gibt es keine Exceptions – Fehler werden über Rückgabewerte oder errno signalisiert.

C++
#include <stdexcept>

double teile(double a, double b) {
    if (b == 0) {
        throw runtime_error("Division durch Null!");
    }
    return a / b;
}

int main() {
    try {
        cout << teile(10, 0) << endl;
    } catch (const runtime_error &e) {
        cout << "Fehler: " << e.what() << endl;
    }
    cout << "Programm laeuft weiter" << endl;
}

Ablauf: throw wirft ein Ausnahmeobjekt, die Ausführung springt sofort zum passenden catch-Block (überspringt den Rest von try), danach läuft das Programm normal weiter. e.what() liefert bei Standard-Exceptions eine Fehlermeldung.

Vergleich C: dieselbe Funktion würde in C typischerweise über einen Fehlercode (z. B. -1) oder ein zusätzliches Zeiger-Argument signalisieren, dass etwas schiefgelaufen ist – der Aufrufer muss den Rückgabewert manuell prüfen.
