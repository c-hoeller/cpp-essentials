Jedes C- und C++-Programm braucht eine main-Funktion als Einstiegspunkt.

C

C
#include <stdio.h>

int main(void) {
    printf("Hallo Welt!\n");

    int alter;
    printf("Wie alt bist du? ");
    scanf("%d", &alter);
    printf("Du bist %d Jahre alt.\n", alter);

    return 0;
}

C++

C++
#include <iostream>
using namespace std;

int main() {
    cout << "Hallo Welt!" << endl;

    int alter;
    cout << "Wie alt bist du? ";
    cin >> alter;
    cout << "Du bist " << alter << " Jahre alt." << endl;

    return 0;
}

return 0; am Ende von main signalisiert dem Betriebssystem, dass das Programm erfolgreich beendet wurde (0 = kein Fehler). Wichtige printf-Formatspezifizierer: %d int, %f float/double, %c char, %s String, %lu size_t.

Zeit mit führenden Nullen ausgeben

Für 9 Minuten und 8 Sekunden soll 09:08 erscheinen. Die 0 in %02d bedeutet: mindestens zwei Stellen breit und links mit Nullen auffüllen. Mit reinem std::cout gibst du die Null bei einstelligen Werten vorher selbst aus.

C
int minuten = 9;
int sekunden = 8;

printf("%02d:%02d\n", minuten, sekunden);  // 09:08
C++
int minuten = 9;
int sekunden = 8;

if (minuten < 10) std::cout << '0';
std::cout << minuten << ":";
if (sekunden < 10) std::cout << '0';
std::cout << sekunden << std::endl;  // 09:08
Hier wird vor jedem einstelligen Wert zuerst das Zeichen '0' ausgegeben. So brauchst du weder <iomanip> noch setw/setfill.

Alternative: String-Verkettung

Du kannst die formatierte Zeit zuerst als std::string zusammensetzen und anschließend ausgeben. std::to_string wandelt dabei die Zahlen in Text um.

C++
#include <string>

int minuten = 9;
int sekunden = 8;

std::string zeit =
    std::string(minuten < 10 ? "0" : "") + std::to_string(minuten) + ":" +
    std::string(sekunden < 10 ? "0" : "") + std::to_string(sekunden);

std::cout << zeit << std::endl;  // 09:08
using namespace std; ist praktisch für kleine Programme/Übungen, in größeren Projekten schreibt man besser explizit std::cout, um Namenskonflikte zu vermeiden.
