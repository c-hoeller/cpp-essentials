Schreiben Sie eine Funktion int maxpos(int * arr, int len), die die Position des größten Werts im übergebenen Integer-Array zurückgibt. Erster Befehl der Funktion muss printf("%s\n", __func__); sein.

Beispiel: maxpos({4,1,2,8,9,1}, 6) → 4, da 9 an Position 4 steht.

int maxpos(int *arr, int len)
{
  printf("%s\n", __func__);

  int max_value = arr[0];
  int max_value_index = 0;

  for (int i = 1; i < len; i++)
  {
    if (arr[i] > max_value)
    {
      max_value = arr[i];
      max_value_index = i;
    }
  }

  return max_value_index;
}
