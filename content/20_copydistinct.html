Schreiben Sie eine Funktion copyDistinct mit dem Prototyp int copyDistinct(int * source, int * dest, int anzahl). Sie soll lückenlos ab Position 0 alle Werte aus source nach dest kopieren, dabei aber jeden Wert nur einmal übernehmen – doppelte Werte in source landen also nur einmal in dest. Rückgabewert ist die Anzahl der kopierten (distinct) Werte.

Beispiel: source = {3,6,7,7,2,1,3,3} (8 Werte) → dest = {3,6,7,2,1}, Rückgabewert 5.
⬇ Übungsvorlage herunterladen (copydistinct.cpp)

Selbst lösen, bevor Sie unten die Lösung ansehen – die Vorlage kompiliert eigenständig (inkl. Testgerüst, falls vorhanden).

int copyDistinct(int *source, int *dest, int anzahl)
{
    int count = 0;
    for (int i = 0; i < anzahl; i++)
    {
        bool bereitsVorhanden = false;
        for (int j = 0; j < count; j++)
        {
            if (dest[j] == source[i])
            {
                bereitsVorhanden = true;
                break;
            }
        }
        if (!bereitsVorhanden)
        {
            dest[count] = source[i];
            count++;
        }
    }
    return count;
}
