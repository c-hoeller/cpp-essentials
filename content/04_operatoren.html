Kurzschlussauswertung (short circuit): Bei && wird der rechte Ausdruck nicht mehr ausgewertet, wenn der linke bereits false ist. Analog bei ||, wenn der linke Teil bereits true ist. Das wird z. B. genutzt für if (p != NULL && p->wert > 0), um bei p == NULL keinen Zugriff über p auszuführen.

Präfix vs. Postfix

C / C++
int i = 5;
int a = i++;   // a = 5, danach i = 6 (erst Wert benutzen, dann erhöhen)
int j = 5;
int b = ++j;   // b = 6, j = 6 (erst erhöhen, dann Wert benutzen)
