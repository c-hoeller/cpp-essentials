Schreiben Sie eine Funktion bool ist_palindron(const char * str). Erste Anweisung muss printf("-%s-\n", __func__); sein. Sie prüft, ob die Zeichenkette ein Palindrom ist (vorwärts gelesen dasselbe Wort wie rückwärts gelesen, z. B. HANNAH). Es kommen dabei nur Groß- oder nur Kleinbuchstaben vor.

Beispiel: ist_palindron("hannah") → true, ist_palindron("hello") → false.

Lösung

C++
#include <iostream>
#include <cstdlib>
#include <string.h>
using namespace std;
#include "eval.h"

bool ist_palindron(const char *str)
{
  printf("-%s-\n", __func__);

  int length, half;
  length = strlen(str);
  half = length / 2;
  int j = length - 1;

  for (int i = 0; i < half; i++)
  {
    if (str[i] != str[j])
    {
      return false;
    }
    j--;
  }

  return true;
}
