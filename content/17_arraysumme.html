Erzeugen Sie ein Integer-Array der Länge 10 und füllen Sie es in einer Schleife mit Vielfachen von 17, sodass an Position i der Wert i * 17 steht. Lassen Sie danach den Benutzer eine Zahl von 0 bis 9 eingeben, setzen Sie den Array-Eintrag an dieser Position auf 0 und geben Sie die Summe aller Arraywerte aus.

Beispiele

EingabeAusgabe
0765
1748
4697
⬇ Übungsvorlage herunterladen (arraysumme.cpp)

Selbst lösen, bevor Sie unten die Lösung ansehen – die Vorlage kompiliert eigenständig (inkl. Testgerüst, falls vorhanden).

Lösung

C++
#include <iostream>
using namespace std;

int main()
{
    int arr[10];
    for (int i = 0; i < 10; i++)
        arr[i] = i * 17;

    int position;
    cin >> position;
    arr[position] = 0;

    int summe = 0;
    for (int i = 0; i < 10; i++)
        summe += arr[i];

    cout << summe << endl;

    return 0;
}
