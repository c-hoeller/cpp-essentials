Erzeugen Sie ein Integer-Array der Länge 10 und füllen Sie es in einer Schleife mit Vielfachen von 17, sodass an Position i der Wert i * 17 steht. Lassen Sie danach den Benutzer eine Zahl von 0 bis 9 eingeben, setzen Sie den Array-Eintrag an dieser Position auf 0 und geben Sie die Summe aller Arraywerte aus.

Mini-Cheat-Sheet

  • int arr[10] – Festes C-Array mit zehn Elementen deklarieren.
  • for – Einmal zum Befüllen, einmal zum Aufsummieren verwenden.
  • += – summe += arr[i] ist die Kurzform für summe = summe + arr[i].

Beispiele

EingabeAusgabe
0765
1748
4697

Lösung

C++
#include <iostream>
using namespace std;

int main()
{
    int arr[10];
    for (int i = 0; i < 10; i++)
        arr[i] = i * 17;

    int position;
    cin >> position;
    arr[position] = 0;

    int summe = 0;
    for (int i = 0; i < 10; i++)
        summe += arr[i];

    cout << summe << endl;

    return 0;
}
