Structs fassen mehrere zusammengehörige Werte unter einem Namen zusammen.

C / C++
typedef struct {
    char name[20];
    int alter;
} Person;

Person p = {"Anna", 30};
printf("%s ist %d Jahre alt\n", p.name, p.alter);  // . bei normaler Variable

Person *zeiger = &p;
printf("%d\n", zeiger->alter);   // -> bei Zugriff ueber Zeiger (Kurzform fuer (*zeiger).alter)

enum

C / C++
enum Wochentag { MONTAG, DIENSTAG, MITTWOCH };  // MONTAG=0, DIENSTAG=1, MITTWOCH=2
enum Wochentag heute = DIENSTAG;
if (heute == DIENSTAG) printf("Dienstag!\n");

union (kurz)

Eine union sieht syntaktisch wie ein struct aus, alle Member teilen sich aber denselben Speicherbereich – es ist immer nur ein Member zur gleichen Zeit gültig belegt. Wird selten klausurrelevant abgefragt, aber gut zu kennen.

In C++ dürfen Structs (wie Klassen) auch Methoden und Konstruktoren haben – der einzige technische Unterschied zu class ist die Standard-Sichtbarkeit: bei struct public, bei class private.

Standardwerte direkt im Struct/Klasse (nur C++)

Seit C++11 dürfen Member direkt bei ihrer Deklaration einen Startwert bekommen – ganz ohne Konstruktor. Dieser Wert gilt, wenn beim Erzeugen des Objekts nichts anderes angegeben wird:

C++
struct Zugangsdaten {
    int passwort = 1234;   // Default-Wert, gilt ohne explizite Initialisierung
    int versuche = 0;
};

Zugangsdaten z;             // passwort = 1234, versuche = 0
Zugangsdaten z2{9999, 3};   // ueberschreibt beide Defaults
