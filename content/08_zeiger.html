Ein Zeiger speichert die Adresse einer Variablen. Zeiger sind das zentrale, oft klausurrelevante Thema in C.

C / C++ 
int x = 10;
int *p = &x;      // p zeigt auf die Adresse von x (& = Adressoperator)

printf("%d\n", *p);   // Dereferenzierung: Wert an der Adresse -> 10
printf("%p\n", (void*)p); // Adresse selbst

*p = 20;               // aendert den Wert von x ueber den Zeiger
printf("%d\n", x);     // 20

Zeiger und Arrays

C / C++ 
int arr[3] = {1, 2, 3};
int *p = arr;          // Array-Name zerfaellt zu Zeiger auf 1. Element
printf("%d\n", *p);        // 1  (gleich arr[0])
printf("%d\n", *(p + 1));  // 2  (gleich arr[1])
printf("%d\n", p[2]);      // 3  (Zeiger koennen wie Arrays indiziert werden)

Zeiger auf Zeiger & NULL

C / C++ 
int x = 5;
int *p = &x;
int **pp = &p;         // Zeiger auf Zeiger
printf("%d\n", **pp);  // 5

int *leer = NULL;      // zeigt auf nichts (C++: nullptr bevorzugt)
if (leer != NULL) { /* sicher dereferenzieren */ }
Das Dereferenzieren eines NULL-/uninitialisierten Zeigers (*p ohne gültige Adresse) ist undefiniertes Verhalten und ein klassischer Absturzgrund – vor dem Zugriff immer prüfen.
Zeigerarithmetik rechnet in "Elementen", nicht in Byte: p + 1 bei einem int* springt sizeof(int) Byte weiter.

const bei Zeigern

const kann sich bei einem Zeiger auf zwei völlig unterschiedliche Dinge beziehen: auf den Wert, auf den gezeigt wird, oder auf den Zeiger selbst (also die gespeicherte Adresse). Beides zusammen ist ebenfalls möglich. Das ist einer der beliebtesten Klausur-Stolpersteine.

C / C++ 
int x = 10, y = 20;

// 1) Zeiger auf konstanten Wert - der Wert ist ueber p1 nicht aenderbar
const int *p1 = &x;      // gleichbedeutend mit: int const *p1 = &x;
// *p1 = 5;              // FEHLER: Wert nicht ueber p1 aenderbar
p1 = &y;                 // OK: p1 darf auf etwas anderes zeigen

// 2) konstanter Zeiger - der Zeiger selbst ist fixiert, der Wert aenderbar
int * const p2 = &x;
*p2 = 5;                 // OK: Wert darf geaendert werden
// p2 = &y;              // FEHLER: p2 darf nicht mehr umgebogen werden

// 3) konstanter Zeiger auf konstanten Wert - beides fixiert
const int * const p3 = &x;
// *p3 = 5;              // FEHLER
// p3 = &y;              // FEHLER
Deklaration Wert änderbar? Zeiger umbiegbar?
const int *p Nein Ja
int * const p Ja Nein (muss bei Deklaration initialisiert werden)
const int * const p Nein Nein
Lesehilfe: Lies die Deklaration vom Variablennamen ausgehend nach links. Bei const int * const p3: "p3 ist ein const Zeiger auf ein const int". Faustregel: const bezieht sich immer auf das, was unmittelbar links davon steht – steht ganz links nichts (const also am Zeilenanfang), bezieht es sich auf das, was rechts folgt. Deshalb sind const int *p und int const *p identisch.

In der Praxis begegnet einem const vor allem bei Funktionsparametern: Ein Zeiger auf const signalisiert dem Aufrufer, dass die Funktion die übergebenen Daten nur liest, nie verändert.

C++ 
void ausgeben(const int *p) {
    cout << *p << endl;   // Lesen ist erlaubt
    // *p = 99;           // FEHLER: Schreiben ist verboten
}
// nuetzlich z.B. bei Strings: void ausgeben(const char *text);
