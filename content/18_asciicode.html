Lassen Sie den Benutzer eine Zahl eingeben und geben Sie danach das Zeichen mit diesem ASCII-Code aus.

Mini-Cheat-Sheet

  • static_cast<char> – Wandelt einen Integer lesbar in das Zeichen mit diesem Zeichencode um.
  • std::cin / std::cout – Eine Zahl einlesen und das umgewandelte Zeichen ausgeben.

Beispiele

EingabeAusgabe
66B
502

Lösung

C++
#include <iostream>

using namespace std;

int main()
{
    int input;
    cin >> input;

    cout << char(input) << endl;

    return 0;
}
