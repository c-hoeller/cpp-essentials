Lesen Sie eine Gleitpunktzahl ein und geben Sie ihren Sinus und Cosinus aus. Keine weiteren Ausgaben. Der vorgegebene, gekennzeichnete Code am Anfang und Ende von main darf nicht verändert werden.

⬇ Übungsvorlage herunterladen (sincos.cpp)

Selbst lösen, bevor Sie unten die Lösung ansehen – die Vorlage kompiliert eigenständig (inkl. Testgerüst, falls vorhanden).

Lösung

C++
#include <iostream>
#include <cmath>

using namespace std;

int main()
{
    double number;
    cin >> number;

    cout << sin(number) << " " << cos(number) << endl;

    return 0;
}
