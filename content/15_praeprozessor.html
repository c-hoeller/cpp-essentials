C / C++
#define PI 3.14159
#define QUADRAT(x) ((x) * (x))   // Klammern um x und den Gesamtausdruck sind wichtig!

double flaeche = PI * QUADRAT(5);   // wird zu: 3.14159 * ((5) * (5))

#ifndef MEINHEADER_H     // Include Guard: verhindert Mehrfach-Einbindung
#define MEINHEADER_H
// Header-Inhalt
#endif
Ohne Klammern, z. B. #define QUADRAT(x) x * x, würde QUADRAT(2 + 3) textuell zu 2 + 3 * 2 + 3 = 11 statt der gewünschten 25 – ein klassischer Makro-Fallstrick.

static & extern

C / C++
int zaehler() {
    static int count = 0;   // wird nur EINMAL initialisiert, Wert bleibt zwischen Aufrufen erhalten
    count++;
    return count;
}
// zaehler() liefert nacheinander aufgerufen: 1, 2, 3, ...

static int nurHierSichtbar = 5;  // static auf Dateiebene: nur in dieser .c/.cpp-Datei sichtbar
extern int ausAndererDatei;      // Variable ist in einer anderen Datei definiert
KonstruktBedeutung
static in FunktionVariable behält ihren Wert über mehrere Aufrufe hinweg
static auf DateiebeneSichtbarkeit auf die aktuelle Datei beschränkt (interne Bindung)
externVerweist auf eine Definition in einer anderen Datei
const vs. #defineconst ist typsicher und vom Compiler geprüft, #define ist reiner Textersatz ohne Typprüfung
