Speicher, dessen Größe erst zur Laufzeit bekannt ist, wird auf dem Heap angelegt.

C: malloc / calloc / realloc / free

C
#include <stdlib.h>

int n = 5;
int *arr = (int*) malloc(n * sizeof(int));  // n ints, uninitialisiert
if (arr == NULL) {
    // Speicher konnte nicht reserviert werden
    return 1;
}
for (int i = 0; i < n; i++) arr[i] = i;

int *arr2 = (int*) calloc(n, sizeof(int));  // wie malloc, aber mit 0 initialisiert
arr = realloc(arr, 10 * sizeof(int));       // Groesse aendern

free(arr);
free(arr2);

C++: new / delete

C++
int *p = new int(42);     // einzelner int, initialisiert mit 42
delete p;

int *arr = new int[5];    // Array von 5 ints
arr[0] = 1;
delete[] arr;             // Array-Form von delete!
Speicherlecks: Jedes malloc/new braucht ein passendes free/delete. Wird das vergessen, bleibt der Speicher bis Programmende belegt (Memory Leak). Für Arrays mit new[] muss zwingend delete[] (nicht nur delete) verwendet werden.
