Der Rest einer Ganzzahldivision a % b lässt sich auch durch fortlaufendes Subtrahieren bestimmen: solange a >= b ist, wird b von a abgezogen, bis a < b ist – der verbleibende Rest ist das Ergebnis. Lassen Sie den Benutzer a, dann b eingeben, geben Sie in der Schleife nach jeder Subtraktion den neuen Wert von a aus und am Ende nochmals das Gesamtergebnis. Keine weiteren Ausgaben.

Mini-Cheat-Sheet

  • while (a >= b) – Wiederholen, bis der Rest kleiner als der Divisor ist.
  • -= – Kurzform für a = a - b; nach jeder Subtraktion den Zwischenwert ausgeben.
  • Modulo-Idee – Der verbleibende Wert entspricht a % b für positive Eingaben.

Beispiele

EingabeAusgabe
5 75
22 715 8 1 1
35 728 21 14 7 0 0

Lösung

C++
#include <iostream>
using namespace std;

int main()
{
    int a, b;
    cin >> a >> b;

    while (a >= b)
    {
        a -= b;
        cout << a << endl;
    }

    cout << a << endl;

    return 0;
}
