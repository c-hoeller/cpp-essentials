Lassen Sie den Benutzer Höhe, Breite und Länge einer Kiste eingeben, danach Höhe, Breite und Länge von Schachteln (jeweils in dieser Reihenfolge). Berechnen Sie, wie viele Schachteln vollständig in die Kiste passen – ohne Drehen, jede Seite bleibt an der entsprechenden Kistenseite ausgerichtet. Geben Sie nur das Ergebnis aus.

Mini-Cheat-Sheet

  • Ganzzahldivision – kiste / schachtel liefert die Anzahl ganzer Schachteln pro Richtung.
  • Produkt – Die drei Anzahlen pro Dimension miteinander multiplizieren.

Beispiele

EingabeAusgabe
1 2 3 1 2 31
2 4 6 1 2 38
4 5 8 1 2 316

Lösung

C++
#include <iostream>

using namespace std;

int main()
{
    int arr[6];
    cin >> arr[0] >> arr[1] >> arr[2] >> arr[3] >> arr[4] >> arr[5];

    int anzahl_hoehe = arr[0] / arr[3];
    int anzahl_breite = arr[1] / arr[4];
    int anzahl_laenge = arr[2] / arr[5];

    cout << anzahl_hoehe * anzahl_breite * anzahl_laenge << endl;

    return 0;
}
