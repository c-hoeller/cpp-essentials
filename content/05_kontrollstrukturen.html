C / C++
if (note <= 4.0) {
    printf("bestanden\n");

switch (tag) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        printf("Wochentag\n");
        break;
    case 6:
    case 7:
        printf("Wochenende\n");
        break;
    default:
        printf("ungueltig\n");
}

for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}

int i = 0;
while (i < 5) {
    printf("%d ", i);
    i++;
}

int j = 0;
do {
    printf("%d ", j);
    j++;
} while (j < 5);   // Rumpf laeuft mindestens einmal, auch wenn j < 5 anfangs falsch waere

break beendet die innerste Schleife/switch sofort, continue springt direkt zur nächsten Iteration.

Ohne break läuft ein switch-Case in den nächsten Case "durch" (Fallthrough) – das ist in C und C++ identisch und eine häufige Fehlerquelle.
Die geschweiften Klammern {} nach if/else/Schleifen sind nur Pflicht, wenn mehr als eine Anweisung folgen soll – bei genau einer Anweisung sind sie optional. Empfehlenswert ist es trotzdem, immer {} zu setzen: sonst führt eine später ergänzte zweite Zeile leicht zu einem Bug, weil sie nicht mehr Teil des if-Zweigs ist.
C / C++
if (x > 0)
    printf("positiv\n");   // OK: nur EINE Anweisung, {} nicht zwingend

if (x > 0)
    printf("positiv\n");
    printf("wird IMMER ausgefuehrt\n");  // Achtung: gehoert NICHT mehr zum if!
