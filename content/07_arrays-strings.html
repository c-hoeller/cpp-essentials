Arrays

C / C++
int zahlen[5] = {10, 20, 30, 40, 50};
printf("%d\n", zahlen[0]);   // 10 - Index beginnt bei 0
zahlen[2] = 99;                // ueberschreibt 30

int matrix[2][3] = { {1,2,3}, {4,5,6} };
printf("%d\n", matrix[1][2]); // 6

Mehrdimensionale Arrays durchläuft man typischerweise mit verschachtelten for-Schleifen – die äußere Schleife läuft über die Zeilen, die innere über die Spalten:

C / C++
int matrix[2][3] = { {1,2,3}, {4,5,6} };

for (int zeile = 0; zeile < 2; zeile++) {
    for (int spalte = 0; spalte < 3; spalte++) {
        printf("%d ", matrix[zeile][spalte]);
    }
    printf("\n");   // Zeilenumbruch nach jeder Zeile
}
C/C++ prüfen Array-Grenzen zur Laufzeit nicht. Ein Zugriff auf zahlen[10] bei einem 5er-Array ist undefiniertes Verhalten (kann abstürzen, falsche Werte liefern oder "zufällig" funktionieren) – nicht automatisch ein Fehler zur Compile-Zeit.

C-Strings (char-Arrays)

C
#include <string.h>

char name[20] = "Anna";        // endet automatisch mit '\0'
printf("%s hat %lu Zeichen\n", name, strlen(name));

char ziel[40];
strcpy(ziel, name);            // kopieren
strcat(ziel, " Schmidt");      // anhaengen
if (strcmp(name, "Anna") == 0) // Vergleich (0 = gleich)
    printf("Treffer\n");

C++ std::string

C++
#include <string>
using namespace std;

string name = "Anna";
string voll = name + " Schmidt";     // + statt strcat
cout << voll.length() << endl;       // Laenge
cout << voll.substr(0, 4) << endl;   // Teilstring "Anna"
if (name == "Anna") cout << "Treffer" << endl;  // == statt strcmp
C (char[])C++ (std::string)
Terminierungmanuelles \0automatisch verwaltet
Längestrlen(s)s.length() / s.size()
Verkettenstrcat(a, b)a + b
Vergleichstrcmp(a, b) == 0a == b
std::string bietet mit .compare(andererString) eine Alternative zu ==, die – wie strcmp in C – nicht nur 0 (gleich) liefert, sondern auch negative/positive Werte für die lexikografische Reihenfolge: a.compare(b) ist 0 bei Gleichheit, <0 wenn a alphabetisch vor b steht, sonst >0.
