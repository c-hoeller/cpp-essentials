Schreiben Sie eine Funktion bool enthaelt_zahl(const char * str). Erste Anweisung muss printf("-%s-\n", __func__); sein. Die Funktion prüft, ob die Zeichenkette ausschließlich aus Ziffern besteht und mindestens eine Ziffer enthält – nur dann liefert sie true.

Mini-Cheat-Sheet

  • const char* – C-Strings werden als Zeiger auf nullterminierte Zeichen übergeben.
  • std::strlen – Liefert die Zeichenanzahl eines C-Strings; Header <cstring> nötig.
  • '0' bis '9' – Ein Zeichen ist eine Ziffer, wenn es in diesem Zeichenbereich liegt.
Beispiel: enthaelt_zahl("123") → true, enthaelt_zahl("12a") und enthaelt_zahl("") → false.

Lösung

C++
#include <iostream>
#include <cstdlib>
#include <string.h>
#include "eval.h"
using namespace std;

bool enthaelt_zahl (const char * str)
{
    printf("-%s-\n", __func__);

    int len = strlen(str);

    if (len < 1)
        return false;

    for (int i = 0; i < len; i++)
    {
        if (str[i] < '0' || str[i] > '9')
            return false;
    }

    return true;
}
