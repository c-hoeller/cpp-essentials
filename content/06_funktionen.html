Eine Funktion braucht Rückgabetyp, Namen und Parameterliste. In C müssen Funktionen vor ihrer Verwendung deklariert (Prototyp) oder definiert sein.

C
// Prototyp (Deklaration) – meist im Header oder oben in der Datei
int quadrat(int x);

int main(void) {
    printf("%d\n", quadrat(4));  // 16
    return 0;
}

// Definition
int quadrat(int x) {
    return x * x;
}

Eine Deklaration (Prototyp) sagt dem Compiler nur, dass eine Funktion mit dieser Signatur existiert – die Definition enthält den tatsächlichen Funktionskörper. Eine vorherige Deklaration ist immer dann nötig, wenn eine Funktion aufgerufen wird, bevor ihre Definition im Code erscheint (z. B. wenn sich zwei Funktionen gegenseitig aufrufen).

Call by Value, Call by Address & Call by Reference

Es gibt drei Arten, Parameter zu übergeben: Call by Value (Standard, Kopie – Änderungen wirken sich nicht auf das Original aus), Call by Address (ein Zeiger wird übergeben – in C die klassische Methode, um ein Original zu verändern) und Call by Reference (nur C++, eine Referenz auf das Original).

C
// Call by Address (C): Aenderung ueber Zeiger
void swapC(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
// Aufruf: swapC(&x, &y);
C++
// Call by Reference (C++): Aenderung ueber Referenz (kein & beim Aufruf noetig)
void swapCpp(int &a, int &b) {
    int tmp = a;
    a = b;
    b = tmp;
}
// Aufruf: swapCpp(x, y);

Nur C++: Default-Parameter & Überladung

C++
double potenz(double basis, int exponent = 2) { /* ... */ }
potenz(3.0);      // exponent = 2 (Default)
potenz(3.0, 3);   // exponent = 3

// Ueberladung: gleicher Name, unterschiedliche Parameterliste (nur C++ moeglich)
int addiere(int a, int b) { return a + b; }
double addiere(double a, double b) { return a + b; }

Rekursion vs. Iteration

C / C++
int fakultaet(int n) {
    if (n <= 1) return 1;       // Abbruchbedingung
    return n * fakultaet(n - 1); // rekursiver Aufruf
}

Fast jede Rekursion lässt sich auch iterativ (mit einer Schleife) lösen – hier dieselbe Funktion iterativ:

C / C++
int fakultaetIterativ(int n) {
    int ergebnis = 1;
    for (int i = 2; i <= n; i++) {
        ergebnis *= i;
    }
    return ergebnis;
}

Ein zweites klassisches Rekursionsbeispiel: die Ziffern einer Zahl einzeln ausgeben.

C / C++
void zeigeZiffern(int n) {
    if (n < 10) {
        printf("%d\n", n);   // letzte Ziffer erreicht: Abbruchbedingung
        return;
    }
    zeigeZiffern(n / 10);     // erst alle vorherigen Ziffern ausgeben
    printf("%d\n", n % 10);  // dann die aktuelle letzte Ziffer
}
