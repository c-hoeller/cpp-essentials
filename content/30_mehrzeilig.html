Schreiben Sie eine Funktion void ausgabeMehrzeilig(const string & str), die die übergebene Zeichenkette buchstabenweise ausgibt und nach jedem '.'-Zeichen (direkt nach dessen Ausgabe) einen Zeilenumbruch erzeugt.

Mini-Cheat-Sheet

  • std::string::size_type – Passender, vorzeichenloser Indextyp für Stringlängen.
  • std::string::length – Bestimmt die Schleifengrenze.
  • char-Vergleich – Nach dem Zeichen '.' direkt einen Zeilenumbruch ausgeben.
Beispiel: ausgabeMehrzeilig("Gregory.Peck") gibt zwei Zeilen aus: Gregory. und Peck.

Lösung

C++
#include <iostream>
#include <cstdlib>
#include <string>
using namespace std;
#include "eval.h"

void ausgabeMehrzeilig(const string &str)
{
    for (string::size_type i = 0; i < str.length(); i++)
    {
        cout << str[i];
        if (str[i] == '.')
            cout << endl;
    }
}
