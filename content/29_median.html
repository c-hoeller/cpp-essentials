Lassen Sie den Benutzer drei unterschiedliche Zahlen eingeben und geben Sie diejenige aus, die zahlenmäßig in der Mitte liegt (von der es also eine kleinere und eine größere gibt). Keine weiteren Ausgaben.

Mini-Cheat-Sheet

  • std::min / std::max – Mit Initializer-Liste aus <algorithm> kleinsten und größten Wert bestimmen.
  • Initializer-Liste – {x, y, z} fasst die drei Werte für min und max zusammen.
  • Summe - Extremwerte – Bei drei verschiedenen Zahlen bleibt genau der mittlere Wert übrig.

Beispiele

EingabeAusgabe
1 3 22
3 6 13

Lösung

C++
#include <iostream>
#include <algorithm>
using namespace std;

int main()
{
    int x, y, z;
    cin >> x >> y >> z;

    int kleinstes = min({x, y, z});
    int groesstes = max({x, y, z});

    cout << (x + y + z - kleinstes - groesstes) << endl;

    return 0;
}
